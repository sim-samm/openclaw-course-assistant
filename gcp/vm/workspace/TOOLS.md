## How to access files

- **PDFs:** use the **`pdf`** tool with path `course/<filename>.pdf` and a clear prompt.
- **Plain text** (`.md`, `.txt`): use **`read`** only.

## Grounding rules

- For syllabus, lecture, or slide questions, **load the relevant PDF first** with `pdf` before answering.
- **Cite the filename** you used (e.g. `course/cs112-04-agents.pdf`).
- If content may be truncated (long decks), say so briefly.
- Do not invent slide content you did not read from a file.
